**Features**
  . AI-powered study assistance
  . Question answering system
  . Smart responses using Gemini API
  . Hugging Face integration
  . Google Colab development environment
  . LLM-based conversational assistant
  . Easy deployment and testing
**Technologies Used**
  . Python
  . Google Colab
  . Hugging Face
  . Gemini API
  . Large Language Models (LLMs)
**Workflow**
    --> User asks study-related questions
    --> Application sends request to LLM
    --> Gemini API processes the query
    --> AI generates smart responses
    --> Results displayed to the user
